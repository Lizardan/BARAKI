# Plan0909 — Прислужник Древних как главный мотив расы

Дата: 2026-09-09. Формат: подробный план с контекстом для агента (можно передать другому агенту/нейронке для продолжения).

## 1. Цель (итоговое решение)

Сделать **прислужника (servant)** ключевой механикой расы Древних (Faceless):

1. **Отдельный юнит вместо «×0.5 от живого Melee».** Создать `UNIT_FACELESS_SERVANT` (60 HP / 0 брони / 4–5 dmg / AS 1 / range 1.5 / speed 4 / bounty 0) и префаб `Faceless_Servant.prefab` (scale 1.25, без оружия). Спавн берёт статы из этого профиля напрямую.
2. **Единый призыв.** `Raise the Drowned` (RaiseDrownedBehaviour) и `Call of the Abyss` (пассивка caster, бонус) дают **одного и того же** прислужника.
3. **Труп переиспользуется один раз (no double).** `TryApplyCallOfTheAbyss` должен потреблять труп после успешного спавна (иначе с одного трупа можно и пассивка, и Raise).
4. **Слот 10 main-здания у Древних** = «Призыв глубин» вместо «Волны света»: каждый живой бараков владельца спавнит servant-ов = размер его текущей волны × 2. Люди и др. расы сохраняют Волну света (Ледяное кольцо — слот 9 — не меняется ни у кого).
5. **Feast on the Fallen удалить**, заменить бонус-супер (слот 6) на «Поедание прислужника»: при HP < 50% Супер автоматически съедает ближайшего своего прислужника → heal = max HP прислужника (60), +15% AS на 5 с, cooldown поедания 3 с.
6. **Servant-киты героям Древних (упрощённо):** каждый обычный герой/титан = Human-база + **одна** замена на servant-призыв «Зов глубин»; ветераны сохраняют сигнатуру (60–63) + servant-замена одного Human-слота. Полный редизайн всех уников НЕ делаем.
7. **Треки башен:** заменить только #5 и #7 (см. дизайн ниже).
8. Везде переименовать «мини-меле / MiniMelee» → «прислужник / Servant».

## 2. Жёсткие правила и гейты

- **Race-гейт:** всё servant-связанное — только раса Faceless (`RaceId == "Faceless"` / `FacelessRaceId` в `RaceDefinition`). Люди и будущие расы не меняются.
- **Wire v22 `UnitDefId = UnitRole.ToString()`** — прислужник это роль `Melee`, не новая роль; маркер servant — `BonusKitRules.SummonBonusSlot = 13` (НЕ игровой слот, диапазон 1–12; `MatchesUnit`/`IsFacelessBonus` его игнорируют; `bonusSlot` в wire — byte 0–255).
- Визуальный scale вычисляется клиентом (`localScale = prefab.localScale × presenterScale`) — префаб scale 1.25 работает у всех.
- **Не реализовывать** `status: deferred`/`mvp: false` из GDD без обновления `TODO.md`.
- Тех-стек: C# 12, Unity 6000.6.0f1, URP 17.6; gameplay/UI — **UniTask/UniRx** (НЕ `Awaitable` в gameplay), только bootstrap — `Awaitable`. Никогда `Task`/`async void`.
- UI — только UI Toolkit + `UIBindingScope` + UniRx (`ReactiveProperty`/`ReactiveCommand`).

## 5. Фазы работы

### Фаза 1 — Прислужник как юнит (префаб + статы + спавн)
1. Создать `UnitDefinition` `UNIT_FACELESS_SERVANT` (60/0/4–5, AS 1, range 1.5, speed 4, bounty 0) рядом с `UNIT_FACELESS_MELEE.asset` (MCP `manage_scriptable_object create`, тип `UnitDefinition`, или `duplicate` + патч полей через `manage_scriptable_object modify`).
2. Меш без оружия: MCP `execute_code` — копия `11_FacelessOneWorker.asset` → `_Servant`, удалить геосеты оружия.
3. Префаб `Faceless_Servant.prefab`: на базе `Faceless_Melee.prefab`, scale 1.25, меш `_Servant`, без оружия; сохранить как pfab (MCP `manage_prefabs create_from_gameobject`/`manage_asset duplicate` + патч).
4. `SummonMinion` (`MatchCombatSystem.cs:4065`): статы брать из servant-профиля напрямую (не `FindMinionSourceStats`). Проверить, где `SummonMinion` вызывается (RaiseDrownedBehaviour, CallOfTheAbyss) — единый путь. `FindMinionSourceStats` удалить/заменить.
5. `UnitVisualCatalog`: ветка servant-префаба (роль Melee, маркер SummonBonusSlot).
6. Переименовать в коде/комментах/тултипах: `MiniMeleeStatScale`/`MinionStatScale` → удалить (статы из профиля); «мини-меле» → «прислужник».
7. Тесты: servant-профиль, спавн-статы; `read_console` — без ошибок.

### Фаза 2 — Труп не переиспользуется
1. `TryApplyCallOfTheAbyss` (`MatchCombatSystem.cs:3345`): принять/найти `CombatCorpseState` и `ConsumeCorpse` после успешного спавна servant-а.
2. Проверить `faceless-unit-bonuses.md` — если там есть «добивание не создаёт трупа»/«no corpse on execute» — синхронизировать.
3. Тесты.

### Фаза 3 — Слот 10 маin-здания: «Призыв глубин» (только Древние)
1. `BuildingAbilityRules`: расовый вариант слота 10. Для Faceless: имя «Призыв глубин», описание, те же лимиты (L2+, 150 мана, CD 180 с). Ледяное кольцо слот 9 не трогать.
2. `MatchController.TryCastBuildingAbility` (стр. 1381): race-гейт (по `RaceDefinition` владельца) + ветка: для каждого **живого** бараков владельца спавнить servant-ов = `SquadCompositionDefinition.TotalUnits` текущего состава волны барака × 2 (fallback `BarracksManualCallRules` при неполном составе уровня). Rally-позиции бараков.
3. UI-лейблы (`GetDisplayName`/`GetEffectDescription`), wire-контракт не ломать (id способности по слоту).
4. Тесты: число servant-ов на живой бараков.

### Фаза 4 — Feast → «Поедание прислужника» (слот 6)
1. Удалить: `AbilityIds.FacelessFeast`, пассивку/хук `TryApplyFeastOnTheFallen`, поля стаков, ассет `Abilities/feast-on-the-fallen.asset`, упоминания в ките Супер (`CreateFacelessBonus`, слот 6).
2. Новая механика A2: Супер при HP < 50% автоматически съедает ближайшего **своего** servant-а → heal 60, +15% AS 5с, CD 3с. 4. Тесты: триггер <50%, heal, бафф, CD, предельный случай без servant-ов.
