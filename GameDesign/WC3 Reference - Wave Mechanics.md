# WC3 Reference — Wave Mechanics & Economy

> Извлечено из JASS-скрипта карты **Survival Chaos Reborn v1.58c** (`war3map.j`, 2.8 MB, 2612 обфусцированных функций). Механики **не** копируются 1:1, используются как референс-точки для дизайна BARAKI.

## Структура базы (WC3)

| Постройка | Роль |
|-----------|------|
| **Fortress** | Главное здание |
| **3× Barracks** | Спавнеры волн (per-lane) |
| **4× Tower** | Оборона |
| **Gate / Altar** | Герои / дополнительные структуры |

> BARAKI уже отражает это: `BUILDING_MAIN` + 3 `BUILDING_BARRACKS` + 4 `BUILDING_TOWER` = 8 зданий.

## Волны / интервалы спавна

| Barracks level | Интервал | Примечание |
|----------------|----------|-----------|
| старт (первая волна) | **15s** | после начала матча |
| L1 | **40s** | |
| L2 | **37s** | −3s |
| L3 | **34s** | −3s |
| L4 | **33s** | −1s |

- У каждого barracks **свой таймер** (не синхронизированы между lane) — совпадает с решением BARAKI «per-barracks».
- Уничтожение Top/Uppper/Right/Left/Bottom/Middle Barracks — отдельные игровые сообщения.

## Пассивные апгрейды тиров (4 тира)

Пассивные способности зданий/юнитов, усиливающие армию:

| Tier | HP | Armor | Attack |
|------|-----|-------|--------|
| T1 | +40 | +2 | +5% |
| T2 | +65 | +4 | +8% |
| T3 | +90 | +6 | +11% |
| T4 | +115 | +8 | +14% |

> Логика «тир → кумулятивные статы» похожа на stat research BARAKI (`UPG_MELEE_DMG` +3%/level, `UPG_ARMOR` +3%/level), но в WC3 это **уровни зданий**, а не отдельные исследования.

## Экономика

- Источники золота (мультиборд): **Fortress, mid-lane, нейтралы, salvage**.
- Мультиборд отслеживает: `Total Gold`, `Normal Gold (Ng)`, `Gold/min (Gm)`, `Ng/Re/Gm 30-40`, `Ng/Re/Gm 40-50` (зоны доходности).
- Стартовое золото/интервалы пассивки — в JASS-константах (детали в дампе прошлой сессии).

## Режимы игры (пик)

| Режим | Описание |
|-------|----------|
| **All Pick** | Все расы открыты |
| **All Random** | Случайная раса |
| **Three Race Pick** | Выбор из 3 рас |
| **Tournament** | Турнирный режим |

> BARAKI (2 расы MVP) — дизайн не предусматривает пик рас, но режимы полезны для планирования фазы 2.

## Замечания для BARAKI

1. **Интервал первой волны** в WC3 = 15s, потом 33–40s. У BARAKI сейчас `BALANCE_WAVE_INTERVAL_BASE = 35s` (L1) и формула `/1.05^(level-1)` → L4 = 30.24s. Разница: WC3 уменьшает интервал **ступенчато** (−3/−3/−1s), BARAKI — плавно. Стоит решить, нужна ли первая «быстрая» волна 15s для темпа старта.
2. **Пассивка тиров** (HP/AR/атк одновременно) — интересная альтернатива «одному треку на тип». Можно использовать как направление для race-wide прокачки.
3. **Мультиборд доходности** (`Gold/min`, зоны 30-40/40-50) — готовый каркас UI-метрик для BARAKI (например, в Match Flow / hud).
